Where to start

  1. Open Start Here and read how to choose and print a pattern.
  2. Measure yourself with the Fit & Measurement Guide.
  3. Print the test square on page 1 of a pattern and check it measures 2 inches.
  4. Make a test garment (muslin) before cutting your final fabric.
