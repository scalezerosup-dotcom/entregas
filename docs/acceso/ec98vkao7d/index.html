Where to start

  1. Open Start Here and read how the patterns are organized.
  2. Knit a gauge swatch before any project.
  3. Pick a Beginner pattern from Volume 1 or 2 for your first project.
  4. Use the bonuses to learn new techniques: loom knitting, crochet, macrame and more.
